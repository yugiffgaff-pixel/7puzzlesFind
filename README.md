# 七巧板

在浏览器里打开 `index.html`。给出一块轮廓，页面会判断它能不能用标准七巧板拼成；能拼成时，在轮廓上画出七块的分割线，并给出从低到高的摆放顺序。

计算在浏览器里完成，不需要服务器。图片不会上传。

## 三种输入

- **经典图形**：十二块已知能拼成的轮廓，用来看分割线和步骤。
- **点顶点**：在格点上围图形。边只能是水平、垂直或 45°，面积要正好是 8（16 个最小直角三角形）。
- **上传剪影**：一块实心图形，白底或黑底都可以。程序提取外轮廓，按这张图自己的像素尺寸把边收到水平、垂直或 45°。顶点可以不落在同一张整数网格上，七块也能离开整格交点来拼。对不齐，或是弯曲的轮廓，会说明原因，不会把任意图硬切成七块。

拼不出时，可以查看图库里形状最接近、而且确实能拼成的一块。那是另一块图形，不是你的轮廓被改过。

平行四边形可以翻面。七块都要用上，不能重叠，也不能留缝。
